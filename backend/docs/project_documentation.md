# 微博热搜数据分析系统

---

## 一、项目背景与目标

### 1.1 项目背景

随着社交媒体的快速发展，微博作为中国最大的社交媒体平台之一，其热搜榜反映了社会热点和公众关注点的实时变化。通过对微博热搜数据的采集、分析和挖掘，可以深入了解社会舆论趋势、用户关注点变化以及热点话题的传播规律。

在大数据应用领域，实时数据采集、数据分析挖掘和可视化展示是核心技术能力。本项目旨在通过构建一个完整的微博热搜数据分析系统，展示大数据技术在社交媒体分析中的应用。

### 1.2 项目目标

1. **实时数据采集**：构建定时爬虫系统，自动采集微博热搜数据
2. **数据质量保障**：建立数据清洗和预处理流程，确保数据质量
3. **深度分析挖掘**：运用聚类分析、情感分析、异常检测等技术深入分析热点话题
4. **智能预测模型**：构建热门话题预测模型，预测话题热度走势
5. **可视化展示**：构建交互式可视化仪表板，直观展示分析结果
6. **智能问答**：集成大模型，实现自然语言问答功能

### 1.3 预期成果

- 完整的微博热搜数据采集系统
- 多维度数据分析报告
- 热门话题预测模型（准确率90%+）
- 交互式可视化仪表板
- 智能问答系统

## 三、实施过程

### 3.1 数据采集

#### 3.1.1 爬虫架构

**模块位置**: `spider/crawler.py`

- **数据来源**: 微博热搜榜API
- **采集频率**: 每10分钟自动采集一次
- **采集内容**: 排名、话题标题、热度值、标签、是否新话题等

**核心功能**:
1. **HTTP请求封装**: 使用Requests库发送请求，处理响应
2. **数据解析**: 解析JSON响应，提取关键字段
3. **异常处理**: 网络超时、请求失败自动重试
4. **数据持久化**: 调用存储模块保存数据

#### 3.1.2 定时调度

**模块位置**: `spider/scheduler.py`

- 使用Python Threading实现定时任务
- 支持三种运行模式：
  - `once`: 单次采集
  - `continuous`: 持续定时采集
  - `status`: 查看爬虫状态

#### 3.1.3 状态监控

**模块位置**: `spider/status_monitor.py`

- **健康检查**: 定期检查爬虫运行状态
- **统计报告**: 每日采集统计、成功率分析
- **日志记录**: 详细的运行日志和错误日志

#### 3.1.4 数据存储

**模块位置**: `spider/storage.py`

- **CSV存储**: 结构化数据存储到CSV文件
- **文件管理**: 自动按日期创建数据文件
- **数据格式**: UTF-8编码，支持中文

### 3.2 数据预处理

#### 3.2.1 数据清洗

**模块位置**: `preprocess/cleaner.py`

**清洗步骤**:
1. **去重处理**: 去除重复的话题记录
2. **缺失值处理**: 填充或删除缺失数据
3. **异常值过滤**: 过滤不合理的热度值
4. **数据格式标准化**: 统一时间格式、数值格式

#### 3.2.2 特征工程

**模块位置**: `preprocess/feature.py`

**特征构建**:

| 特征类别 | 特征名称 | 说明 |
|----------|----------|------|
| 热度特征 | avg_hot, max_hot, min_hot, std_hot | 热度统计特征 |
| 排名特征 | avg_rank, best_rank, worst_rank | 排名统计特征 |
| 变化特征 | hot_change_rate, rank_change, hot_volatility | 变化率和波动率 |
| 生命周期 | appear_count, duration_hours | 出现次数和持续时间 |
| 时间特征 | hour_cos, hour_sin, dow_cos, dow_sin | 时间周期性特征 |
| 标签特征 | is_new_ratio, is_hot_ratio | 新话题/热门话题比例 |

**实体识别**:
- 使用正则表达式提取人名、地名、机构名
- 关键词提取和标签分析

### 3.3 数据分析与可视化

#### 3.3.1 聚类分析

**模块位置**: `analysis/clustering.py`

**聚类算法**:
- **K-Means**: 基于热度和持续时间的硬聚类
- **DBSCAN**: 密度聚类，识别异常话题群

**聚类结果**:
- 将话题分为不同生命周期类型：爆款话题、持续热点、短期热点、普通话题

#### 3.3.2 情感分析

**模块位置**: `analysis/sentiment.py`

- 使用SnowNLP进行中文情感分析
- 计算每个话题的情感倾向（正面/负面/中性）
- 分析情感随时间的变化趋势

#### 3.3.3 异常检测

**模块位置**: `analysis/anomaly.py`

**检测类型**:
- **热度异常**: 热度值突增或突降
- **排名突变**: 排名急剧变化
- **爆款话题**: 短时间内热度飙升的话题
- **新晋话题**: 首次进入热搜榜的话题

**算法**: Isolation Forest孤立森林算法

#### 3.3.4 词云分析

**模块位置**: `analysis/wordcloud.py`

- 关键词提取和词频统计
- 生成词云图展示热门关键词
- 按标签分类统计关键词

#### 3.3.5 关联分析

**模块位置**: `analysis/correlation.py`

- 话题共现分析：哪些话题经常同时出现在热搜榜
- 热度相关性分析：话题之间的热度变化相关性
- 话题聚类网络构建

#### 3.3.6 可视化展示

**模块位置**: `visualization/dashboard.py`

**页面功能**:

| 页面 | 功能说明 |
|------|----------|
| 📊 数据概览 | 热搜TOP20、标签分布、最新数据 |
| 📈 热度趋势 | 话题热度演化曲线、排名变化 |
| 🏷️ 标签分析 | 标签统计、分布可视化 |
| ⏰ 时间分布 | 小时/星期分布分析 |
| 🎯 聚类分析 | 3D聚类可视化、预测结果展示 |
| 💭 情感分析 | 情感分布、情感反转话题 |
| 📝 词云分析 | 热门关键词TOP30 |
| 🔍 异常检测 | 异常类型分布、详情列表 |
| 🤖 智能问答 | Qwen大模型对话 |
| 🎬 排名动画 | TOP10排名动态变化 |

### 3.4 建立预测模型

#### 3.4.1 模型架构

**模块位置**: `analysis/prediction.py`

**模型选择**:
- **RandomForest分类器**: 准确率92.3%，AUC 1.0
- **GradientBoosting分类器**: 准确率92.3%，AUC 0.83

**特征选择**:
1. max_hot (最高热度) - 最重要特征
2. avg_rank (平均排名)
3. best_rank (最佳排名)
4. appear_count (出现次数)
5. hot_change_rate (热度变化率)

#### 3.4.2 模型训练流程

```
原始数据 → 特征提取 → 数据划分 → 模型训练 → 模型评估 → 预测部署
```

**数据划分**:
- 训练集: 80%
- 测试集: 20%
- 使用分层抽样保证类别均衡

**评估指标**:
- 准确率 (Accuracy): 92.3%
- AUC值: 1.0
- 交叉验证均值: 0.94

#### 3.4.3 预测结果

**输出示例**:

| 话题 | 预测概率 | 当前热度 | 预测结果 |

| 国乒男团3比0大胜日本 | 99.9% | 355万 | 热门 |
| 盼弟 来弟 | 99.9% | 75万 | 热门 |
| 村民被眼镜王蛇咬伤 | 99.0% | 70万 | 热门 |

## 四、总结

### 4.1 项目成果

1. **完整的数据采集系统**: 实现定时爬虫，自动采集微博热搜数据
2. **多维度数据分析**: 聚类、情感、异常检测、词云、关联分析
3. **高精度预测模型**: RandomForest分类器，准确率92.3%
4. **交互式可视化仪表板**: 10个功能页面，实时展示分析结果
5. **智能问答系统**: 集成阿里云Qwen大模型，支持自然语言查询

### 4.2 技术亮点

1. **模块化架构**: 清晰的分层设计，易于维护和扩展
2. **自动化流程**: 从数据采集到分析可视化的全流程自动化
3. **多算法融合**: 机器学习、深度学习、统计分析多种技术融合
4. **交互式体验**: 3D可视化、动态排名动画、实时数据更新
5. **智能交互**: 大模型集成，支持自然语言问答

### 4.3 未来展望

1. **数据存储优化**: 引入时序数据库(如InfluxDB)存储海量历史数据
2. **实时流处理**: 使用Kafka+Spark Streaming实现实时数据分析
3. **模型优化**: 尝试深度学习模型(LSTM/Transformer)进行时序预测
4. **多平台扩展**: 支持微博、抖音、B站等多平台数据采集
